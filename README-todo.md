# Java To-Do List Application

A console-based task management application built in Java that allows users to create, manage, and persist tasks using object-oriented programming and file handling.

---

## Features

- Add new tasks
- View existing tasks
- Delete tasks by index
- Mark tasks as complete
- Persistent storage using file I/O (tasks saved between sessions)

---

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- File I/O (BufferedReader, FileWriter, PrintWriter)
- ArrayList data structure
- Console-based user input (Scanner)

---

## How It Works

- Tasks are stored as objects containing a name and completion status
- User interacts through a menu-driven console interface
- Data is saved to a local text file (`tasks.txt`)
- On startup, saved tasks are automatically loaded into memory

---

## Key Concepts Demonstrated

- Classes and objects
- Encapsulation of data
- CRUD operations (Create, Read, Update, Delete)
- Persistent data storage
- Input validation and control flow
